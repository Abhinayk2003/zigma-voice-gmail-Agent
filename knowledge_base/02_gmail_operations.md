# Zigma Voice Gmail Agent — Gmail Operations

## Search

Search retrieves Gmail messages matching the user's request.

Example:

"Show me emails from Ravi."

The search criteria are derived dynamically from the user's request. The returned Gmail messages become the available result set for subsequent references such as "first email" or "second email."

## Read

Read displays or summarizes the contents of a selected Gmail message.

Examples:

- "Read the first email."
- "Read the second email."
- "Read that email."

The application resolves the referenced message before reading it.

## Send

Send creates and sends a new Gmail message.

A send request can provide recipient, subject, body, CC, and BCC information. When required information is missing, the application can use the conversational flow to complete the request rather than requiring a rigid command format.

Recipient and message details must be dynamic and must not be hard-coded.

## Draft

Draft creates an email without sending it.

Draft content should be based on the user's request and any relevant conversational context.

## Reply

Reply sends a response to an existing Gmail message or thread.

The original message or thread must be resolved by the application. The language model must not invent the Gmail message ID or thread ID.

Example:

"Show me emails from Ravi."
"Read the second email."
"Reply to that email and say Thanks for the update."

## Star and Unstar

Star marks the selected Gmail message as starred.

Unstar removes the star from the selected Gmail message.

The target message must be resolved from Gmail data or application state.

## Mark Read and Mark Unread

Mark Read changes the selected message to a read state.

Mark Unread changes the selected message to an unread state.

## Delete

Delete is a destructive Gmail operation.

A delete request must not immediately execute the Gmail deletion.

The application first creates a pending confirmation action and asks the user for explicit confirmation.

After confirmation, the application executes the Gmail operation and moves the message to Trash.

If the user cancels, the pending delete is cancelled and the Gmail message is not deleted.

## Threads

Thread operations use Gmail thread information returned by the Gmail API or stored application context.

Thread IDs must never be generated by the language model.
